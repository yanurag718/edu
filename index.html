Comprehensive Syllabus & Modules

Detailed week-by-week curriculum structured for industry requirements.

Module 1 • Weeks 1 - 4 AWS Core & Networking

VPC Architecture, EC2, IAM & Cloud Storage

Design custom Virtual Private Clouds (VPC), configure public/private subnets, Security Groups, IAM roles/policies, EC2 instances, S3 bucket storage policies, and Elastic Load Balancers.

Capstone Deliverable: Highly available multi-AZ cloud network architecture setup.
Module 2 • Weeks 5 - 8 Docker & Kubernetes

Containerization & Microservices Orchestration

Writing production Dockerfiles, multi-stage builds, Docker Compose stack, Kubernetes Pods, Deployments, Services, Ingress Controllers, Helm charts, and Amazon EKS setup.

Capstone Deliverable: Deploy microservice app stack on AWS EKS with Kubernetes Ingress.
Module 3 • Weeks 9 - 12 IaC & CI/CD Pipelines

Terraform Automation & GitHub Actions

Infrastructure as Code (IaC) with Terraform modules, state management, automated testing, GitHub Actions workflows, Jenkins pipelines, and automated artifact deployment.

Capstone Deliverable: End-to-end zero-downtime CI/CD deployment pipeline.

Curriculum & Practical Labs

Real business case studies from e-commerce, finance, and tech industries.

Module 1 • Weeks 1 - 3 SQL & Database Querying

Complex JOINs, Window Functions & CTEs

Relational database fundamentals, SQL aggregations, inner/outer JOINs, Subqueries, Common Table Expressions (CTEs), and Window Functions (ROW_NUMBER, RANK, LAG/LEAD).

Capstone Deliverable: Querying transactional records for multi-million row retail store ledger.
Module 2 • Weeks 4 - 6 Python Data Science

Data Cleaning, Pandas & Seaborn Visuals

Python data structures, Pandas DataFrames, handling missing values, exploratory data analysis (EDA), statistical distribution, and Seaborn data visualizations.

Capstone Deliverable: Customer churn analysis model built in Jupyter Notebooks.
Module 3 • Weeks 7 - 12 BI & Executive Dashboards

Power BI DAX & Tableau Dashboards

Data modeling, DAX measures, KPI cards, custom drill-downs, dynamic filters, and presenting insights to C-suite executives.

Capstone Deliverable: Interactive Power BI Business Intelligence Dashboard.
